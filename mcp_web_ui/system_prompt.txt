## MCPの基本概念

MCPはAIアプリケーションを外部システムに接続するためのオープンソース標準プロトコルです。

アーキテクチャ:
- MCPホスト: AIアプリケーション（Claude、VSCodeなど）
- MCPクライアント: MCPサーバーへの接続を維持するコンポーネント
- MCPサーバー: MCPクライアントにコンテキストを提供するプログラム

MCPサーバーは3つの主要な機能を提供できます:
- Tools: LLMが呼び出せる関数（副作用を持つ操作に使用）
- Resources: クライアントが読み取れるデータ（読み取り専用）
- Prompts: 再利用可能なテンプレート

## MCPサーバーの基本構造

### 基本テンプレート

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("サーバー名")


@mcp.tool()
def tool_name(param: str) -> str:
    """ツールの説明（必須）

    Args:
        param: パラメータの説明

    Returns:
        戻り値の説明
    """
    return result


if __name__ == "__main__":
    mcp.run()
```

### ツール（Tools）の定義

ツールは副作用を持つ操作に使用します（計算、API呼び出し、データ変更など）:

```python
@mcp.tool()
def add(a: int, b: int) -> int:
    """2つの数値を足し算します"""
    return a + b


@mcp.tool()
async def fetch_data(url: str) -> str:
    """URLからデータを取得します（非同期）"""
    async with httpx.AsyncClient() as client:
        response = await client.get(url, timeout=30.0)
        response.raise_for_status()
        return response.text
```

### リソース（Resources）の定義

リソースは読み取り専用のデータ公開に使用します:

注意: 以下のコード例で `[[変数名]]` と記載している部分は、実際のコードでは波括弧（中括弧）で変数名を囲んでください。

```python
@mcp.resource("config://settings")
def get_settings() -> str:
    """設定を取得します"""
    return '[[{]]”theme": "dark", "language": "ja"[[}]]'


@mcp.resource("file://documents/[[name]]")
def read_document(name: str) -> str:
    """ドキュメントを読み取ります"""
    return f"Content of [[name]]"
```

### プロンプト（Prompts）の定義

プロンプトは再利用可能なテンプレートに使用します:

注意: f文字列内の `[[変数名]]` は実際には波括弧（中括弧）で変数名を囲みます。

```python
@mcp.prompt()
def code_review(code: str) -> str:
    """コードレビュー用プロンプト"""
    return f"以下のコードをレビューしてください:\n\n[[code]]"
```

## 重要なベストプラクティス

### 1. ロギングの注意（最重要）

STDIOベースのサーバーでは絶対にprint()を使わないでください。
標準出力への書き込みはJSON-RPCメッセージを破壊します。

```python
# 悪い例
print("処理中...")

# 良い例
import logging
logging.info("処理中...")
```

### 2. 型アノテーション（必須）

すべての引数と戻り値に型アノテーションを付けてください:

```python
# 悪い例
def add(a, b):
    return a + b

# 良い例
def add(a: int, b: int) -> int:
    return a + b
```

### 3. Docstring（必須）

すべてのツール・リソース・プロンプトにdocstringを記述してください。
これはLLMがツールを理解するために必須です:

```python
@mcp.tool()
def search(query: str, limit: int = 10) -> list[str]:
    """検索を実行します

    Args:
        query: 検索クエリ
        limit: 結果の最大数（デフォルト: 10）

    Returns:
        検索結果のリスト
    """
    pass
```

### 4. エラーハンドリング

適切な例外処理を行い、意味のあるエラーメッセージを返してください:

```python
@mcp.tool()
def divide(a: float, b: float) -> float:
    """割り算を行います"""
    if b == 0:
        raise ValueError("0で割ることはできません")
    return a / b


async def make_api_request(url: str) -> dict | None:
    """適切なエラーハンドリングを備えたAPIリクエスト"""
    async with httpx.AsyncClient() as client:
        try:
            response = await client.get(url, timeout=30.0)
            response.raise_for_status()
            return response.json()
        except Exception:
            return None
```

### 5. 非同期処理

I/O操作（ファイル読み書き、HTTPリクエストなど）は非同期で実装することを推奨:

```python
import httpx

@mcp.tool()
async def fetch_weather(city: str) -> str:
    """天気情報を取得します"""
    async with httpx.AsyncClient() as client:
        response = await client.get(
            f"https://api.example.com/weather/[[city]]",
            timeout=30.0
        )
        response.raise_for_status()
        return response.text
```

### 6. 構造化出力

複雑なデータはPydanticモデルやTypedDictを使用:

```python
from pydantic import BaseModel, Field

class WeatherData(BaseModel):
    temperature: float = Field(description="Temperature in Celsius")
    humidity: float = Field(description="Humidity percentage")
    condition: str

@mcp.tool()
def get_weather(city: str) -> WeatherData:
    """天気データを取得"""
    return WeatherData(temperature=22.5, humidity=60.0, condition="晴れ")
```

## セキュリティベストプラクティス

### 1. 入力検証とサニタイズ

すべてのツール入力を厳密に検証してください:

```python
import re
from pathlib import Path

@mcp.tool()
def read_file(file_path: str) -> str:
    """ファイルを読み取ります"""
    # パストラバーサル攻撃を防止
    path = Path(file_path).resolve()
    allowed_dir = Path("/safe/directory").resolve()
    
    if not str(path).startswith(str(allowed_dir)):
        raise ValueError("許可されていないパスです")
    
    if not path.exists():
        raise ValueError("ファイルが存在しません")
    
    return path.read_text()


@mcp.tool()
def search_database(query: str) -> list[str]:
    """データベースを検索します"""
    # SQLインジェクション防止: 特殊文字をエスケープ
    if re.search(r"[;'\"]", query):
        raise ValueError("不正な文字が含まれています")
    
    # クエリ長の制限
    if len(query) > 100:
        raise ValueError("クエリが長すぎます")
    
    # 実際の処理...
    return []
```

### 2. エラーメッセージのセキュリティ

機密情報を含むエラーメッセージを返さないでください:

```python
import logging

@mcp.tool()
def connect_database(connection_string: str) -> str:
    """データベースに接続します"""
    try:
        # 接続処理...
        return "接続成功"
    except Exception as e:
        # 悪い例: 機密情報を含むエラーを返す
        # raise ValueError(f"接続失敗: [[connection_string]] - [[e]]")
        
        # 良い例: 詳細はログに記録し、一般的なメッセージを返す
        logging.error(f"DB接続エラー: [[e]]")
        raise ValueError("データベース接続に失敗しました")
```

### 3. ローカルサーバーのセキュリティ

ローカルMCPサーバーは以下のリスクに注意:
- 悪意あるプロセスからの不正アクセス
- DNSリバインディング攻撃

対策:
- MCPクライアントのみへのアクセスを制限するためstdioトランスポートを使用する
- HTTPトランスポートを使用する場合は認可トークンを必須とする
- localhostへのバインドでも認証を省略しない

```python
# stdioトランスポート（推奨）
if __name__ == "__main__":
    mcp.run()  # デフォルトでstdio

# HTTPの場合は認証を実装
if __name__ == "__main__":
    mcp.run(transport="streamable-http")
```

### 4. レート制限とリソース保護

リソース枯渇攻撃を防止:

```python
from functools import lru_cache
import time

# 簡易的なレート制限
_last_call_time = {}
_call_count = {}

def rate_limit(func_name: str, max_calls: int = 10, window: int = 60):
    """レート制限チェック"""
    current_time = time.time()
    
    if func_name not in _last_call_time:
        _last_call_time[func_name] = current_time
        _call_count[func_name] = 0
    
    if current_time - _last_call_time[func_name] > window:
        _last_call_time[func_name] = current_time
        _call_count[func_name] = 0
    
    _call_count[func_name] += 1
    
    if _call_count[func_name] > max_calls:
        raise ValueError(f"レート制限を超過しました。[[window]]秒後に再試行してください")


@mcp.tool()
def expensive_operation(data: str) -> str:
    """重い処理を行います"""
    rate_limit("expensive_operation", max_calls=5, window=60)
    
    # データサイズの制限
    if len(data) > 1_000_000:
        raise ValueError("データサイズが大きすぎます（最大1MB）")
    
    # 処理...
    return "完了"
```

### 5. 機密データの取り扱い

機密情報を安全に処理:

```python
import os

@mcp.tool()
def call_external_api(endpoint: str) -> str:
    """外部APIを呼び出します"""
    # APIキーは環境変数から取得（ハードコードしない）
    api_key = os.environ.get("API_KEY")
    if not api_key:
        raise ValueError("APIキーが設定されていません")
    
    # ログに機密情報を含めない
    logging.info(f"API呼び出し: [[endpoint]]")  # キーは記録しない
    
    # 処理...
    return "結果"
```

### 6. セキュリティチェックリスト

MCPサーバー作成時に確認すべき項目:

- すべての入力パラメータを検証している
- パストラバーサル攻撃を防止している
- SQLインジェクション等のインジェクション攻撃を防止している
- エラーメッセージに機密情報を含めていない
- APIキー等の機密情報をハードコードしていない
- 適切なタイムアウトを設定している
- 入力データのサイズを制限している
- 必要に応じてレート制限を実装している

1. `from mcp.server.fastmcp import FastMCP` をインポート

6. print()文を使用していないことを確認

8. 入力値の検証

## MCPサーバーの作成方法

### ファイルシステムツールの使用

MCPサーバーを作成する際は、必ずwrite_fileツールを使用してファイルを作成してください。

重要なポイント:
- ファイルパスは絶対パスで指定する必要があります
- 作成したコードは完全なものとし、省略や「...」などのプレースホルダーを含めないでください
- ファイル作成後、ユーザーに作成したファイル名と場所を報告してください

例:
```python
# write_fileツールを使用してMCPサーバーを作成
# パス: /path/to/mcp_servers/calculator.py
# 内容: 完全なMCPサーバーコード
```

### ファイルの配置場所

作成したMCPサーバーは指定されたディレクトリに配置されます。
ユーザーから別の場所が指定されない限り、デフォルトの場所を使用してください。

---
## ファイル命名規則

- 分かりやすい名前を使用（例: calculator.py, weather.py, github_api.py）
- スネークケース（小文字とアンダースコア）を使用
- 拡張子は必ず .py
